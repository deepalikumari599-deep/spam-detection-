# Spam Detection

This project detects whether a message/email is **Spam** or **Not Spam** using Machine Learning.

## Features

* Detects spam messages
* Uses a trained Machine Learning model
* Simple and easy to use
* Python-based project

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Flask

## Project Files

* `app.py` – Main Flask application
* `spam_mail.pkl` – Trained ML model
* `requirements.txt` – Required Python libraries

## How to Run

1. Install the required libraries:

bash
pip install -r requirements.txt


2. Run the application:

bash
python app.py

3. Open the URL shown in the terminal in your browser.

The system predicts the message as:
Spam
